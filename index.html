(03) Process

How I build AI systems.

Six steps I keep coming back to, from a fuzzy idea to an agent people can rely on — each one backed by something I've shipped.

01 / 06 · Define

Pin down the job

Every build starts with a contract: inputs, outputs and failure modes. iWebify turns plain-English requirements into validated, executable app schemas before anything is generated.

02 / 06 · Retrieve

Ground it in real data

RAG with hybrid retrieval. Sarthi Kalyan pairs structured eligibility filters with semantic embeddings across 750+ schemes; Sentinel runs local embeddings on ChromaDB + FAISS at $0 inference API cost.

03 / 06 · Reason

Orchestrate agents, not prompts

LangGraph state machines split work across focused agents — multi-agent matching in Sarthi Kalyan, and a 9-stage compiler pipeline with dependency-aware context isolation in iWebify.

04 / 06 · Act

Act with guardrails

Models propose; rules decide. CaseVera keeps AI investigation separate from deterministic verdict and action logic, with explicit uncertainty and evidence provenance on every decision.

05 / 06 · Evaluate

Measure before you trust

iWebify's 20-prompt production and adversarial suite tracks success, repair retries, latency and cost. In Sarthi Kalyan, BigQuery decision logs surfaced a silent scoring bug before it reached users.

06 / 06 · Ship

Deploy, then make it fast

SHIELD on AWS cut analysis time from 8 minutes to 4.2 seconds and API costs by 97% with a scam-fingerprint cache. Sarthi Kalyan runs on Google Cloud with WhatsApp and web front-ends.
